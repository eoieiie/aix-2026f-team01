# 팀 규칙 / Team Rules

1주차 활동지(week-01.md)에서 합의한 내용의 요약.

1. **역할은 아직 안 나눈다.** Issue를 맡은 사람이 그 건을 끝까지 본다. 기술 역할은 5주차에 정한다.

2. **연락은 디스코드로.** 평일 12시간 안에 답하고 결정사항들은 Issue에 적는다.

3. **끝났다는 기준이 없으면 리뷰하지 않는다.** 리뷰는 다음 순번 사람이 맡고, 승인 하나 받으면 머지한다.

4. **내부 마감은 이틀 전에, 제출은 하루 전에.** 늦을 것 같으면 미리 말한다.

5. **AI를 아주 잘 사용하되, 숨기지 않는다.** 판단은 `PROMPTS.md`에 남기고, 이해 못 한 코드는 올리지 않는다.
