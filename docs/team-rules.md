# 팀 규칙 / Team Rules

1주차(`docs/week-01.md`)에 합의한 규칙을 지금 일하는 방식에 맞게 줄였다. 바꾼 것과 뺀 것은 `docs/decisions.md`에 있다.

지금 방식: **만드는 일은 AI에게 시키고, 사람은 무엇을 만들지 정하고 화면으로 확인해 승인한다.**

1. **일은 이슈 하나 단위로, 맡은 사람이 끝까지 본다.** 이슈에는 완료 조건이 있어야 하고, 완료 조건이 없는 PR은 리뷰하지 않는다.
2. **사람이 하는 일은 세 가지다.** 이슈의 완료 조건을 정하고, AI가 만든 화면을 눌러 보고, 승인한다. 브랜치, 커밋, PR, 기록은 AI가 `team/WORKFLOW.md`대로 한다.
3. **승인은 사람이, 이해한 뒤에 한다.** 다음 순번이 PR 댓글의 미리보기 주소에서 완료 조건을 하나씩 눌러 보고, PR 본문의 동작 원리를 읽고 승인한다. 동작 원리를 설명할 수 없으면 승인하지 않는다. 발표에서 질문받는다.
4. **연락은 카카오톡.** 평일 12시간 안에 답한다. 카톡에서 정한 것은 이슈나 PR 댓글, 팀 결정이면 `docs/decisions.md`로 옮긴다. 카톡은 기록이 남지 않는다.
5. **회의는 안건이 있을 때만,** 되도록 수업 직후에 한다.
6. **마감은 이틀 전.** 내부 마감은 LMS 마감 48시간 전, 제출은 24시간 전. 늦을 것 같으면 바로 카톡에 말한다.
7. **AI를 쓴 것은 숨기지 않는다.** 흐름이 끝나면 AI가 PR 본문에 기록을 남기고, 매주 활동지 PR에서 `PROMPTS.md`로 모은다. 실제 개인정보와 키는 AI에게도 저장소에도 넣지 않는다.
8. **의견이 갈리면 명세와 완료 조건으로 정한다.** 이미 시작한 일의 완료 조건은 끝날 때까지 바꾸지 않는다. 그래도 안 갈리면 맛있는 걸 먹으러 간다.
