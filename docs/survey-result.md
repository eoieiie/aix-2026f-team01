# 사전 수요 조사 설문 결과 및 서비스 필요성 분석

7주차 사전 수요 조사 계획(`docs/week-07.md` 태스크 #2)에 따라 실시한 설문 결과와, 그로부터 도출한 밥BTI의 필요성 및 기대 효과를 정리한다.

## 1. 조사 개요

- 조사 기간: 2026-10-27 ~ 2026-10-28
- 응답 인원: 78명 (목표 30명 이상 충족)
- 조사 내용: 모임 메뉴 결정 소요 시간 및 방식, 기존 투표·사다리 도구 불편 사항, 음식 제한 여부, 눈치·부담 경험, '아무거나' 답변에 대한 인식

## 2. 설문에서 확인된 핵심 문제 (밥BTI가 필요한 이유)

### 2.1 "아무거나" 회피와 결정 피로로 인한 시간 낭비

- 응답자의 76.9%(60명, 5점 척도 평균 4.08점)가 '아무거나'라는 답변 때문에 메뉴 결정에 고민한 적이 있다고 답했다(보통 이상 포함 시 91.0%).
- 메뉴를 정하는 데 5분 이상을 소비하는 응답자가 46.2%(36명)이며, 이 중 14명(17.9%)은 10분 이상 고민한다고 답했다.
- 결정 방식은 다수결(60.3%, 47명) 외에 한 명이 주도해서 정하는 경우(28.2%, 22명)가 많아, 주도자에게 선택과 책임 부담이 집중되는 구조다.

### 2.2 과반수의 음식 제한과 눈치로 인한 침묵

- 전체 응답자의 55.1%(43명)가 못 먹거나 피하는 음식이 있다고 답했다(비선호 33명, 알레르기 12명(15.4%), 다이어트 4명, 매운 음식 2명 등 복수 응답).
- 알레르기·식단 관리 등으로 메뉴 고르기가 눈치 보인 경험이 있는 응답자는 35.9%(28명)이며, 메뉴가 마음에 안 들었지만 눈치 보여 그냥 먹은 적이 있는 응답자(4~5점)는 41.0%(32명, 보통 이상 포함 69.2%)다.
- 처음 보는 사람과의 모임에서 메뉴를 제안하거나 고르는 것이 부담스럽다는 응답 역시 41.0%(32명, 보통 이상 포함 71.8%)로 나타났다.

### 2.3 기존 도구(단톡방 투표·사다리타기)의 구조적 한계

- 기존 투표나 사다리·룰렛 도구를 사용해 본 61명 중 47명(77.0%, 전체 응답자 대비 60.3%)이 불편함을 겪었다고 응답했다.

| 기존 도구 불편 사항 (복수 응답) | 응답 수 | 경험자 대비 비율 (전체 대비) |
| :--- | :---: | :---: |
| 투표하지 않은 사람이 있어 마냥 기다려야 함 | 33명 | 54.1% (42.3%) |
| 투표 후보에 못 먹는 음식이 포함되어 있음 | 14명 | 23.0% (17.9%) |
| 사다리·룰렛이 투표 결과(표 수)를 반영하지 않고 완전 무작위라 불공평함 | 11명 | 18.0% (14.1%) |
| 누가 무엇을 투표했는지 다 보여 불편함 (익명성 부재) | 5명 | 8.2% (6.4%) |

## 3. 실제 주관식 응답 원문

7주차 완료 조건에 따라 설문 응답자가 작성한 주관식 원문(곤란했던 상황 및 '아무거나'에 대한 생각) 중 대표 사례를 가공 없이 옮긴다.

### 가장 최근에 여럿이 메뉴 정하다 곤란했던 상황

1. "아무도 주도적으로 어딜 가자고 의견내는 사람이 없어서 고민만 몇 십분 했던 경험이 있음."
2. "각자 먹고싶은 음식이 다른데 한명은 다이어트중이라 메뉴선정하다가 싸울 뻔 했습니더"
3. "알러지때문에 못가는 식당이 있어서 자신으로 인해 메뉴가 바뀌는 때가 있다"
4. "8명이서 아무도의견을 안내서 10분넘게 기다렸던 상황 있었음"
5. "해산물을 못 먹는데 지은들이 회를 먹자고 할때"
6. "메뉴를 정할때 분탕치기(이거도 싫어, 저거도 싫어)"
7. "모두 결정을 못해서 정말 오랫동안 메뉴를 고민하고도 결정을 못해서, 결국 눈 앞에 보이는 곳으로 선택하였다."

### '아무거나'라는 답변에 대한 생각

1. "아무거나 라고 말하고 아무데나 간다면 좋은 대답이지만 아무거나라고 말해놓고 메뉴 제안하면 그거말고,, 라고 한다면 회피형..이라고 생각합니다"
2. "아무거나 먹겠다고 하면 나도 아무거나 먹어도 상관없어서 결론이 안나는 경우가 많았습니다"
3. "못 먹는 걸 제외하고, 선호하는 음식이나 종류에 대해서라도 정보를 알려줬으면 좋겠습니다."
4. "자기주장 부족과 책임을 떠넘기려는 느낌도 있다. 순수하게 아무거나 먹어도 된다고 배려하는 말일수도 있겠지만."
5. "결정권을 떠넘기는 느낌. 대신 그렇게 했으면 다음 제안에 군말없이 따라줘야한다고 생각합니다.."

## 4. 문제 해결 매핑 및 기대 효과

### 4.1 밥BTI의 문제 해결 구조

| 설문에서 확인된 문제 | 밥BTI의 해결 방식 |
| :--- | :--- |
| "아무거나" 회피 및 주도자 결정 부담 (76.9%) | 후보 등록 → 익명 투표 → 가중치 룰렛의 단계별 흐름으로 결정 책임을 사람이 아닌 시스템이 진다 |
| 못 먹는 음식이 후보에 섞이고 눈치가 보임 (제한 보유 55.1%, 눈치로 수용 41.0%) | 못 먹는 재료와 음식을 사전에 등록하면 판이 열릴 때 후보에서 자동 제외하며, 누구 때문에 빠졌는지는 익명 처리한다 |
| 누가 무엇을 찍었는지 다 보여 솔직한 의사 표현이 어려움 | 서버 권한 기반 완전 익명 투표를 적용해 참여자 간 눈치 싸움을 없앤다 |
| 기존 사다리·룰렛의 불공정성 및 미투표자 대기 병목 | 투표 수에 비례해 칸 크기가 커지는 가중치 룰렛을 적용하고, 정한 인원이 다 고르면 바로 돌리며 오지 않는 사람이 있으면 방장이 인원을 줄일 수 있게 한다 |

### 4.2 도입 시 기대 효과

1. 메뉴 결정 시간 및 감정 소모 단축: 단톡방에서 미투표자를 기다리거나 "아무거나" 공방으로 5~10분 이상 지체되던 의사결정 과정을 초대 링크 공유 한 번으로 빠르게 마무리한다.
2. 눈치 없는 안전한 식사 환경 조성: 알레르기(15.4%)나 비선호·식단 제한(55.1%)을 매번 입으로 밝히지 않아도 후보가 자동 필터링되므로, 눈치 보며 억지로 먹는 상황(41.0%)을 예방한다.
3. 다수결의 공정성과 룰렛의 결정력 결합: 표가 많이 모인 메뉴일수록 당첨 확률이 높아져 기존 무작위 사다리의 불공정성 불만을 해소하면서도, 룰렛 결과에 대한 심리적 수용성을 높인다.
4. 지속 가능한 모임 기록 축적: 모임별로 식사 기록이 쌓여 지난 모임에서 무엇을 먹었는지 함께 볼 수 있다.
