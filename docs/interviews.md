# 사용자 인터뷰

README 2절 "인터뷰 3명 요지"와 `ETHICS.md` 1절 "당사자에게 확인했는가"의 근거다. 3주차에 계획했지만 기록이 남지 않아 11주차 중간 데모 전에 다시 한다.

## 하는 법

- 누구를: 팀 밖의 대학생 중 친구와 같이 밥을 자주 먹는 사람. 세 명 중 한 명은 되도록 못 먹는 것(알레르기, 채식, 할랄 등)이 있는 사람
- 얼마나: 한 명에 5분. 질문 세 개
- 시작 전에: "팀 과제 기록에 이름 없이 요지만 남긴다"고 말하고, 괜찮다고 하면 한다. 녹음하지 않는다
- 적지 않는 것: 이름, 학번, 학과, 연락처, 얼굴 사진. 대상은 "같은 학교 학생" 정도로만 적는다
- 적는 것: 답은 들은 말에 가깝게 한두 줄. 지어내거나 다듬지 않는다. 써 보게 했을 때는 어디서 멈췄는지 본 대로 적는다
- 어디에: 이슈 댓글에 아래 칸을 복사해 채운다. 활동지 PR에서 이 파일로 옮긴다

## 질문

1. 최근에 친구들이랑 같이 밥 먹을 때 메뉴를 어떻게 정했어요? 얼마나 걸렸어요?
2. 메뉴를 정할 때 곤란했던 적이 있어요? 못 먹는 걸 말 꺼내기 어려웠던 적은요?
3. (https://babti.expo.app 에서 모임을 만들어 초대 링크를 보내고, 같이 한 판을 끝까지 해 본 뒤) 어디가 헷갈렸어요? 이걸 쓸 것 같아요? 왜요?
