# 데모데이 시연 시나리오

2026-11-19 처음 씀 (eoieiie). 데모데이는 12/2(수), 우리 팀은 네 번째다(8팀, 12팀, 9팀, 1팀). 팀당 10~15분 안에 준비, 발표, 질의, 채점이 들어간다. 발표자료는 LMS 14주차 과제(12/1 23:59)와 교수자 컴퓨터 바탕화면 `AI+X_ICT` 폴더에 미리 둔다. 시연 영상(3분 이내)은 12/1까지 찍어 둔다.

채점표(14주차 `팀명_채점표.xlsx`)에서 시연이 직접 걸린 칸은 둘이다.
- 완성도 30: 입력부터 결과까지 멈추지 않고, 발표에서 말한 기능이 모두 시연에 나온다. 사람이 손으로 대신 처리하면 깎인다
- 실용성 30: 인터뷰 실제 발언, 사용자 테스트 뒤 고친 점

그래서 시연은 "한 판을 끝까지, 끊지 않고"가 먼저이고, 기능을 많이 보여 주는 것은 그다음이다.

## 1. 등장인물 (가상 인물)

발표와 영상에 나오는 이름과 상황은 지어낸 것이다. 화면에 "가상 인물"을 적는다.

| 이름 | 역할 | 폰 | 시연에서 하는 일 |
|---|---|---|---|
| 민준 | 방장, 소융대 2학년 | 아이폰 앱(테스트플라이트) | 모임 QR 띄우기, 판 열기, 돌리기 |
| 서연 | 새우를 못 먹는다 | 안드로이드 앱 | QR로 들어오기, 못 먹는 것 |
| 지호 | 아무거나 괜찮다 | 웹(폰 카메라로 QR) | "아무거나 괜찮아요" |
| 하은 | 메뉴를 직접 적는다 | 웹 | 목록에 없는 메뉴 적기 |

앱 두 대와 웹 두 대를 섞어 "앱이 없어도 QR만 찍으면 된다"를 같이 보여 준다.

영상(3분)에는 장면 사이에 인터뷰 발언 자막 3개와 "사장님 동의 인증샷" 한 컷을 더한다.

## 3. 제휴 장면은 실제로 동의한 가게만

- 장면 6, 7의 "광고"와 쿠폰은 사장님이 동의한 가게에서만 켠다. 켜는 법은 `scripts/partner-on.sql`
- 동의한 가게가 0곳이면 장면 7은 일반 카페 추천만 보이고, 발표에서는 "제휴는 다음 단계" 슬라이드로 넘긴다. 없는 제휴를 있는 것처럼 보이지 않는다
- 결제와 정산은 없다. 쿠폰은 코드를 보여 주는 것까지

### "추천으로 뜨면 가겠는가"는 가설로 말한다

메뉴가 정해진 바로 그 순간에, 걸어서 몇 분인지와 쿠폰이 같이 보이면 갈 가능성이 높다고 본다. 아직 잰 적은 없다. 발표에서는 "가설"로 말하고, 시연 기간 쿠폰 받기 수(`coupon_claims`)를 숫자로 보여 줄 수 있으면 보여 준다.

## 4. 사장님 방문 (11/20 ~ 11/28)

대상은 학생 제휴를 이미 해 본 카페부터다. 소융대 학생회(LINK)와 첨융대 학생회(SOAR) 제휴 목록에 둘 다 있고, 소융대 "혜택자들" 주간 추천에도 나온 곳: 신디도넛, 이삭토스트, 코지홀리데이, 썬더커피. 다음: UP플레이스, 묵커피바, 시저커피, 코이노커피. 학생회 목록은 갈 곳을 고르는 데만 쓰고 앱 데이터로 옮기지 않는다.

말할 것 (1분)
1. "한양대 에리카 소프트웨어융합대학 학생이고, 수업 팀 프로젝트로 친구들끼리 메뉴를 정하는 앱을 만들고 있습니다"
2. "메뉴가 정해지면 근처 가게를 보여 주는데, 사장님 가게를 '제휴 카페'로 이름만 넣어 시연해도 될지 여쭤보고 싶습니다"
3. "돈은 받지 않고, 결제 기능도 없습니다. 12월 2일 수업 발표에서 쓰고, 원하시면 언제든 뺍니다"
4. (괜찮다고 하시면) "학생에게 주실 수 있는 작은 혜택이 있으면 쿠폰 문구로 넣겠습니다. 없어도 괜찮습니다"

하지 않을 말: 학생회 제휴, 학교 공식, 광고비, 정산.

남길 것
- 동의서 한 장(아래 항목). 사진으로 찍어 팀 드라이브에 두고 #67에 "가게 이름, 날짜, 동의 범위"만 적는다
- 인증샷은 가게 앞이나 메뉴판과 우리 팀. 사장님 얼굴은 동의하실 때만

동의서 항목
- 가게 이름, 날짜, 동의하신 분 성함(서명)
- 앱에 가게 이름과 위치를 "제휴" "광고"로 보여 주는 것: 예 / 아니오
- 쿠폰 문구(있으면)와 기간(12/31까지 등)
- 수업 발표 자료와 시연 영상에 가게 이름, 가게 사진을 쓰는 것: 예 / 아니오
- 돈이 오가지 않고, 원하시면 언제든 빼는 것
- 연락처는 받지 않는다(필요하면 팀 연락처를 드린다)
