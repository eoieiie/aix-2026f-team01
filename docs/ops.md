# 운영 메모

명세 13절(출시와 운영)의 손으로 하는 일. 규칙은 명세에 있고, 여기는 하는 방법만 적는다.

## 신고 확인 (매일)
- 약관에 "신고는 24시간 안에 확인한다"고 적었다(명세 4-24). 관리자 화면은 없다
- 담당 한 사람이 매일 한 번 Supabase 대시보드 SQL Editor에서 `scripts/reports.sql` 1번을 돌린다. 처리하면 2번으로 표시한다
- 담당: 13주차 회의(11/25)에서 정한다

## 시연 전날
- 실제 주소를 한 번 열어 서버를 깨운다(무료 서버는 일주일 쓰지 않으면 멈춘다)
- 시험 모임과 시험 계정은 만들 때 붙인 고유 접두사(예: `zz_night_`)로만 지운다. 이름이나 조건이 넓은 삭제는 실제 사용자를 지울 수 있다
